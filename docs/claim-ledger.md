The maintained machine-readable ledger is [claim-ledger.yaml](claim-ledger.yaml).
It distinguishes baseline CI, current implementation, historical source-cache
attestation, configured environments and unresolved scientific gates. See also
the exact [project state](orchestration/project-state.json). The old M1-only table

## Canonical continuation boundary

Full-reference canonical preprocessing, runtime/index/source/BQSR qualification,
fixed chr20–22 normalization/benchmark/coverage, and restart publication are
implemented and locally testable. Those statements concern code and synthetic
negative tests. Actual Colab execution, canonical accuracy/resource values,
release, deployed Explorer and canonical website results remain unsupported
until their independently validated evidence exists. The classic BWA canonical
route differs from historical M3 BWA-MEM2 and is recorded as such.
