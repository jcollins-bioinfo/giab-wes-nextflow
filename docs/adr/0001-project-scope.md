# ADR 0001: project scope

**Status:** accepted for v1 foundation (2026-08-29)

## Decision

HG001 Illumina WES dual-caller benchmarking is primary. GATK, DeepVariant, or both share one BAM and normalization/benchmark interface. ONT, somatic, clinical use, and Sarek replacement are excluded.

## Reversal conditions
Pause acquisition if assay target/library association remains unresolved. Scope expansion requires completed v1 evidence and a new ADR.
